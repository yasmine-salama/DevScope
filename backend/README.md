# Backend

The Flask application source code is in this directory.

For the complete project overview, installation instructions, environment configuration, usage guide, and test command, see the [main README](../README.md).

Quick start from this directory:

```bash
python -m venv .venv
# Activate the virtual environment, then:
pip install -r requirements.txt
cp .env.example .env
# Set a strong SECRET_KEY in .env before starting.
python run.py
```
